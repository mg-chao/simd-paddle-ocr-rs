# Public OCR fixtures

The 19 original JPEG files in `corpus/` are copied without modification from
PaddlePaddle/PaddleOCR, commit `ddaa85ddafe1edfbe618b83ca0e8e61dab33155b`
(v2.7.3). See each immutable source URL and SHA-256 in `manifest.json`.

Copyright (c) 2016 PaddlePaddle Authors. All Rights Reserved.
The upstream repository's Apache License 2.0 is preserved in
`PaddleOCR-LICENSE`. Upstream: https://github.com/PaddlePaddle/PaddleOCR

The two derived rotation cases rotate the decoded pixels of `doc/imgs/11.jpg`
clockwise by 90 and 180 degrees, without resampling. The blank case is a white
512x512 image generated by this harness. These modifications are represented
explicitly in the manifest; the original JPEGs remain unmodified.

Expected results are predictions from the pinned SimdPaddleOCR C# CPU reference,
not human transcripts or an OCR accuracy benchmark.
